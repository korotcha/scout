# Горизонтальная юнит-экономика

Одна модель — одна строка. Группы столбцов раскрываются вправо. Добавление модели не открывает редактор. Ввод — светло-жёлтые ячейки; результаты — светло-голубые. Остальные страницы не меняют масштаб.

Срок производства: подтверждённый срок выбранной фабрики, иначе плановый срок модели (45 дней по умолчанию). Запас считается от текущей даты с учётом доставки и параллельной сертификации. Месяц модели можно менять независимо от месяца исходного анализа; точный день сохраняется (с ограничением последним днём месяца).

Дефолты FBW и FBS независимы. Новые модели получают снимки обоих профилей. Переключение сохраняет индивидуальные настройки схемы, общая цена продажи переносится. Сохранённые расчёты не обновляются вместе с дефолтами.

## WB API

«Базы данных → API и подключения». Только владелец может сохранить, проверить, заменить или отключить ключ. Сервер обращается только к фиксированному домену common-api.wildberries.ru; произвольные URL не принимаются. Токен зашифрован AES-GCM с уникальным IV и AAD. Ключ шифрования INTEGRATION_ENCRYPTION_KEY хранится в секретах среды Sites, отдельно от D1. Не удалять и не менять его без миграции зашифрованных значений.

Сохранение нового ключа требует успешного чтения комиссий и тарифов коробов. При ошибке старый ключ и справочник не заменяются. Проверяется именно доступ к этим двум методам, а не ко всем категориям WB API. Ключ не возвращается клиенту и не записывается в журналы. Данные тарифов доступны авторизованным пользователям; изменение подключения — владельцу. Подключение действует для всех месяцев.

Тарифы — снимок на дату успешного обновления. Обновление запускается владельцем; фонового расписания нет. В карточке кнопка «Тарифы WB» подбирает комиссию по точному предмету и схеме и базовую логистику по складу и объёму одной единицы. Подстановка только в пустые ячейки, в том числе ноль считается ручным значением. Расчёт для стандартных коробов от 1 л: первый литр + дополнительные литры × ставка. Коэффициент, уже включённый WB в ставки, повторно не умножается. КГТ, малые объёмы и индивидуальные коэффициенты требуют ручной проверки. Обратную логистику и хранение не выводим из этих ставок.

Методы: /api/v1/tariffs/commission; /api/v1/tariffs/box?date=YYYY-MM-DD. Документация: https://dev.wildberries.ru/docs/openapi/rates

Живое подключение должно быть проверено после ввода владельцем своего ключа; без него успешное получение тарифов не подтверждено.
